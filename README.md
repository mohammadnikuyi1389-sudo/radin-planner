# PARS CODE — Android (Kotlin / Jetpack Compose)

## وضعیت: همه‌ی ۱۰ صفحه ساخته شدن + ویرایش برای وظیفه/عادت/هدف/تراکنش

Splash, Dashboard, برنامه روزانه(*), نمای هفتگی, عادت‌ها, اهداف, برنامه ۱۲هفته‌ای,
پومودورو (تایمر واقعی), کتابخانه, مالی, تنظیمات (DataStore واقعی), پروفایل.

(*) برنامه روزانه فعلاً Placeholder است چون افزودن/تیک‌زدن وظیفه از داشبورد
همون کارکرد رو می‌ده؛ صفحه‌ی اختصاصی‌ش فاز بعدیه.

## این نسخه چی داره که نسخه‌ی قبل نداشت
- افزودن/حذف واقعی: وظیفه (داشبورد + برنامه روزانه)، عادت (long-press=حذف)، هدف (با تاییدیه)، منبع کتابخانه، تراکنش مالی (با تاییدیه، حذف حالا کار می‌کنه)
- برنامه روزانه یک صفحه اختصاصی کامل با تایم‌لاین است (نه Placeholder)
- زنگوله و منو در بالای صفحه واقعاً کار می‌کنن (دیالوگ اعلان + منوی ناوبری کامل)
- Seed data: برنامه ۱۲هفته‌ای واقعاً با ۱۲ هفته پر می‌شه
- تنظیمات → سوییچ اعلان‌ها واقعاً روی DataStore ذخیره می‌شه
- Pomodoro با تایمر واقعی (کوروتین) + ثبت جلسات در Room
- تاریخ‌ها (مهلت هدف، تاریخ تراکنش) همه‌جا جلالی نمایش داده می‌شن
- «امروز» در تمام صفحات هر ۶۰ ثانیه به‌روزرسانی می‌شه (رد شدن از نیمه‌شب باعث فریز شدن داده نمی‌شه)
- ترتیب اجزای عادت‌ها/کتابخانه real و قابل جابه‌جایی (بالا/پایین) است

## هنوز باقی‌مونده (فاز بعدی، اگه خواستی)
- لینک‌کردن اهداف به هفته‌های برنامه ۱۲هفته‌ای
- WorkManager برای یادآور واقعی (dependency هست، wire نشده)
- تست‌ها (unit/UI) — عمداً به‌خاطر صرفه‌جویی توکن رد شد
- آیکون اپ نمادین ساده‌ست، نه گرافیک واقعی لوگو

⚠️ بدون امکان `gradle build` واقعی نوشته شده (بدون اینترنت)؛ قبل از استفاده‌ی جدی یه Gradle sync توصیه می‌شه.
